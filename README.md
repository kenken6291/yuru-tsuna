# ゆるつな（yuru-tsuna）

近所の人や、同じ「好き」の人と、しがらみなしでゆるくつながるコミュニティサイト。

- フロント：GitHub Pages（`index.html` / `style.css` / `app.js` / `config.js`）
- バックエンド：Google Apps Script（`gas/Code.gs`）
- データ：スプレッドシート（会員）、Google ドライブ（プロフィール画像）
- AI：Gemini API（趣味タグ提案・自己紹介の下書き）

```
yuru-tsuna/
├─ index.html
├─ style.css
├─ app.js
├─ config.js      ← GAS の URL はここだけ
├─ gas/
│   └─ Code.gs    ← Apps Script エディタに貼る
└─ README.md
```

## 1. スプレッドシートの構成

シート名：**Users**（`setup()` 実行で自動作成）

| 列 | 項目名 | 内容 |
|---|---|---|
| A | userId | `u_` + ランダム12文字 |
| B | email | 小文字で保存 |
| C | nickname | 20文字まで |
| D | prefecture | 都道府県 |
| E | area | 市区町村など（任意） |
| F | hobbies | カンマ区切り（最大10個） |
| G | bio | 自己紹介（300文字まで） |
| H | iconFileId | ドライブのファイルID |
| I | passwordHash | 本パスワードのハッシュ（SHA-256 × 500回、salt＋pepper） |
| J | salt | ユーザーごとのソルト |
| K | tempHash | 仮パスワードのハッシュ |
| L | tempExpiresAt | 仮パスワード期限（ミリ秒） |
| M | mustChangePassword | TRUE の間はパスワード設定画面を強制 |
| N | failCount | 連続ログイン失敗回数 |
| O | lockedUntil | ロック解除時刻（ミリ秒） |
| P | status | `active` / `suspended`（手で書き換えると利用停止） |
| Q | createdAt | 登録日時 |
| R | updatedAt | 更新日時 |
| S | lastLoginAt | 最終ログイン |

仮パスワードは本パスワードとは別の列（K）に持つので、第三者が「パスワード再発行」を押しても本人の今のパスワードは使えたままです。

## 2. スクリプトプロパティ

Apps Script エディタ →「プロジェクトの設定（歯車）」→「スクリプト プロパティ」

| キー | 必須 | 内容 |
|---|---|---|
| PEPPER | 自動 | `setup()` が自動生成。**絶対に変更・削除しない**（全員ログインできなくなる） |
| GEMINI_API_KEY | AIを使うなら | Google AI Studio で発行したキー |
| GEMINI_MODEL | 任意 | 省略時 `gemini-2.5-flash`。モデルを変えたいときはここだけ書き換え（再デプロイ不要） |
| APP_URL | 任意 | `https://kenken6291.github.io/yuru-tsuna/`（メール本文にリンクが入る） |
| ICON_FOLDER_ID | 自動 | 画像フォルダ。無ければ自動作成 |
| SPREADSHEET_ID | 任意 | スタンドアロンのスクリプトにする場合のみ |

スクリプトプロパティの変更は**再デプロイなしで即反映**されます。

## 3. 初回セットアップ

1. Google ドライブで新しいスプレッドシートを作る（名前例：ゆるつな_会員）
2. メニュー「拡張機能」→「Apps Script」
3. 最初からある `コード.gs` の中身を全部消して、`gas/Code.gs` を貼り付けて保存
4. 上部の関数選択で **setup** を選び「実行」
   - 「承認が必要です」→ アカウントを選ぶ →「詳細」→「（安全ではないページ）に移動」→「許可」
   - スプレッドシート・メール送信・ドライブ・外部通信の権限がまとめて承認されます
5. 「プロジェクトの設定」でスクリプトプロパティ（上の表）を登録
6. 右上「デプロイ」→「新しいデプロイ」
   - 「種類の選択」の歯車 →「ウェブアプリ」
   - 説明：`v1.0.0`
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」→ 表示された **ウェブアプリの URL（…/exec）** をコピー
7. `config.js` の `GAS_URL` に貼り付け
8. GitHub に `yuru-tsuna` リポジトリを作って全ファイルを push →「Settings」→「Pages」→ Branch：`main` / `(root)` → Save
9. ブラウザで GAS の URL を直接開き、`{"ok":true,"app":"ゆるつな","version":"1.0.0",...}` が出れば準備完了

> 「新しいデプロイ」を使うのは **この最初の1回だけ** です。

## 4. GAS を更新しても URL を変えない手順（重要）

コードを直したら、毎回この手順で「同じデプロイ」を新しいバージョンに差し替えます。URL はそのままなので `config.js` は触りません。

1. `Code.gs` を修正し、先頭の `VERSION` を上げる（例：`'1.0.1'`）→ 保存（Ctrl+S）
2. 右上「デプロイ」→ **「デプロイを管理」**
3. 左の一覧で、最初に作ったデプロイ（`v1.0.0` など）を選ぶ
4. 右上の **鉛筆アイコン（編集）** を押す
5. 「バージョン」のプルダウンで **「新バージョン」** を選ぶ ← ここを忘れると古いコードのまま
6. 説明に変更内容（例：`v1.0.1 AIの文言修正`）を書いて「デプロイ」
7. 表示される URL が以前と同じことを確認
8. ブラウザで GAS の URL を開き、`"version":"1.0.1"` になっていれば反映済み
   - アプリの「じぶん」タブ最下部にも `サーバー v1.0.1` と出ます

やってはいけないこと：

- 「デプロイ」→「新しいデプロイ」を押す → **別の URL が増える**（フロントは古い方を見たまま）
- 「テスト デプロイ」の `/dev` URL を `config.js` に入れる → 本人がログイン中のブラウザでしか動かない
- 保存だけして再デプロイしない → `/exec` は前のバージョンのまま

新しい種類の権限が必要になる変更（例：カレンダーを使い始める）をした場合は、デプロイの前にエディタで `setup` を一度実行して承認しておきます。

### clasp を使う場合

```bash
clasp push
clasp deployments                       # 既存のデプロイIDを確認（@HEAD 以外のもの）
clasp deploy -i <デプロイID> -d "v1.0.1"  # 同じIDに上書き → URL は変わらない
```

`-i` を付けずに `clasp deploy` すると新しい URL ができるので注意。

## 5. フロント（GitHub Pages）の更新

- ファイルを直して push すれば 1〜2 分で反映
- スマホで古い画面が出るときは、`index.html` 内の `?v=1.0.0` を3か所とも上げる（`style.css` / `config.js` / `app.js`）。`app.js` 先頭の `FRONT_VERSION` も合わせて上げると確認しやすい

## 6. 仕組みのメモ

- 通信は `Content-Type: text/plain` で JSON を POST → CORS のプリフライトが発生しない。GAS は `ContentService` の JSON を返す
- セッションは CacheService（6時間・使うたびに延長）。切れたらログイン画面へ
- ログイン5回連続失敗で15分ロック
- 仮パスワードは24時間有効。再発行は同じ人につき3分に1回まで
- AI（タグ提案・自己紹介）は1人1時間20回まで、音声おしゃべりは別枠で1時間60回まで
- 音声おしゃべり（好きなこと／自己紹介の2種類）：ブラウザの音声認識（Web Speech API）で聞き取り → GAS の `aiHobbyChat`／`aiBioChat` で Gemini が返事とタグ候補・自己紹介の下書きを返す → 端末の読み上げで返事を声に出す。ユーザー発言6回で自動的にまとめる
- 聞き取りは「話が止まってから3.5秒黙ったら送信」。考えながら話す間で切れないよう、ブラウザが途中で認識を止めても自動でつなぎ直す。待ち時間は `app.js` の `SILENCE_MS` で調整（ひとことも話さないときは15秒で終了）
- 音声認識に非対応のブラウザ（Firefox など）では文字で答える欄だけになる。iPhone は「設定 → Siri」で音声入力がオンになっている必要がある
- スプレッドシートの数式インジェクション（`=` 始まりの入力）を防止済み
- 無料の Google アカウントのメール送信上限は1日100通程度。登録が多い日は上限に注意
